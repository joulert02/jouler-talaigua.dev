# Color

<StatusBadge status="approved" />

A quiet neutral palette with one violet accent. Use these tokens for every color on the site; never write a color value in a component.

## Rules

- **Do** use the accent only to mark interaction: links, focus, the primary action, selection.
- **Don't** use color to build hierarchy; size, weight and space do that.
- **Do** keep dark surfaces off pure black; `--color-bg` is the darkest value.
- **Don't** let `--color-border` carry meaning alone. It is decorative; a control that needs a visible edge uses `--color-text-muted` or a shadow.
- **Do** keep the flag colors for the Colombian flag detail in the footer and the ticket object.
- Selection is accent text on a light mix of the accent over the surface, never white on the accent.
