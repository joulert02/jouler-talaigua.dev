## Rules

- Use the scale for gaps, padding and margins between elements.
- The prototype also uses 6, 10 and 14px often. They stay as local values (`--_name`) until the Home build decides whether they join the scale.
- `--layout-container` is the maximum width shared by Home, Work and case pages. Prose inside it keeps `--measure-prose`.

## Breakpoints

CSS cannot read custom properties inside `@media`, so breakpoints are named constants, written as literal values in media queries.
